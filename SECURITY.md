# Security policy

RAISE is research software for post-hoc explanation. It is not a security boundary and its outputs should not be treated as authoritative incident-response decisions without independent validation.

## Reporting a vulnerability

Please report security-sensitive issues privately through GitHub's **Report a vulnerability** / private vulnerability reporting interface when it is enabled for this repository. Do not include credentials, private log data, production identifiers, or other sensitive material in public issues.

For non-sensitive correctness or reproducibility problems, use the public issue tracker.
